# Текст для установки (русский)

Скопируйте всё, что в рамке ниже, и вставьте в новую сессию Claude Code (вкладка Code в приложении Claude или `claude` в терминале). Две строки ближе к концу можно поменять перед отправкой.

```text
Пожалуйста, установи Reel Studio на этот компьютер. Я не технический человек: делай всё сам, перед каждым шагом коротко говори, что делаешь, и общайся со мной по-русски.

Правила:
- Не меняй ничего, что не нужно по этому списку: никаких системных настроек, других программ и файлов вне названных здесь папок.
- Никогда не запускай то, что требует прав администратора (sudo, окно Windows с запросом разрешения, «Запуск от имени администратора»). Если такой шаг нужен, покажи мне точную команду, скажи, куда её вставить, и подожди, пока я напишу, что готово.
- Если шаг не получился, прочитай ошибку, исправь самым простым способом и одной строкой скажи, что случилось.

1. Проверь компьютер: система и её версия, тип процессора, свободное место на диске и есть ли git. Напиши результат в двух строках. Reel Studio работает на Windows 10 или 11 (64 бита), на Mac с процессором Apple (M1 и новее) и на 64-битном Linux на основе Ubuntu (Ubuntu 22.04/24.04, Zorin OS, Mint), нужно около 10 ГБ свободного места. Если компьютер не подходит, остановись и объясни почему.

2. Установи то, чего не хватает:
   - Windows без Git: покажи мне команду  winget install --id Git.Git -e  (может спросить разрешение), подожди меня и продолжай.
   - Linux без git, curl или tar: покажи мне  sudo apt install -y git curl tar  и подожди меня.
   - Mac без инструментов разработчика: запусти  xcode-select --install  (откроется окно, я нажму «Установить») и подожди меня.

3. Если команда claude не работает в терминале, установи Claude Code только для этого пользователя (права администратора не нужны):
   - Windows, в PowerShell:  irm https://claude.ai/install.ps1 | iex
   - Mac или Linux:  curl -fsSL https://claude.ai/install.sh | bash

4. Установи плагин:
   claude plugin marketplace add SirOxygenFish/reel-studio
   claude plugin install reel-studio@siroxygenfish
   Если он уже установлен, вместо этого выполни  claude plugin update reel-studio@siroxygenfish

5. Найди установленную копию: самая новая папка ~/.claude/plugins/cache/siroxygenfish/reel-studio/<версия>. Для следующих шагов используй её bin/reel-tool (в Windows в PowerShell: bin\reel-tool.cmd). Запусти  reel-tool setup  в фоне: он скачивает 5-8 ГБ и работает от 10 до 30 минут. Каждые несколько минут одной строкой говори, сколько уже сделано. Когда закончит, запусти  reel-tool doctor  и исправь всё, о чём он скажет (шаги с правами администратора показывай мне, как сказано выше).

6. Папка для видео: используй папку, которую я напишу здесь: [оставьте пустым, тогда будет папка по умолчанию]. По умолчанию это папка Reels внутри папки «Видео» (Windows и Linux) или «Фильмы» (Mac). Потом выполни
   reel-tool autostart on --folder "<эта папка>"
   чтобы страница загрузки для телефона запускалась сама при каждом входе в систему. Автозапуск: [да]  (если я написал здесь «нет», пропусти эту команду и скажи, что страницу можно запустить вручную командой  reel-tool phone-link --start ). Затем выполни  reel-tool shortcut on , чтобы на рабочем столе появился значок, который запускает страницу и показывает ссылку для телефона.

7. Выполни  reel-tool phone-link --start --open . В ответе покажи мне ссылку для телефона и QR-код из вывода команды (в блоке кода) и скажи: наведите камеру iPhone на код, откройте страницу в Safari, нажмите «Поделиться», затем «На экран „Домой“».

8. Чётко скажи мне: плагины подключаются только в новой сессии. Эту сессию нужно закрыть и начать новую в папке с видео (покажи полный путь). В приложении: Code, New session, выбрать эту папку.

9. В конце напиши эту шпаргалку слово в слово:
   Каждый день:
   1. iPhone: значок Reel Studio, выбрать ролики, «Отправить».
   2. Приложение Claude: Code, сессия моего компьютера.
   3. Написать: монтируй (и что хочется по-особому).
   4. Дождаться, пока Claude скажет, что готово.
   5. Страница загрузки: «В галерею». Рилс уже в «Фото».

Больше ничего не трогай.
```
