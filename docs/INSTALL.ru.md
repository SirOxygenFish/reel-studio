# Reel Studio: установка

Reel Studio делает из сырых видео с вашим лицом готовые Reels для Instagram: вырезает дубли и паузы, чистит голос, ставит субтитры по словам, рисует анимацию под ваш текст и проверяет результат перед выдачей. Работает внутри Claude Code.

## Что нужно

- Подписка Claude с Claude Code (Pro или Max) и Claude Code в терминале (команда `claude`)
- Один из компьютеров:
  - Windows 10 или 11 (64 бита) с программой Git for Windows
  - Linux на обычном ПК: Ubuntu 22.04 или 24.04, а также Zorin OS, Linux Mint и другие системы на их основе
  - Mac на процессоре Apple (M1 и новее). Mac на Intel не подходит
- Около 10 ГБ свободного места на диске
- Интернет для первой установки

Видеокарта NVIDIA не обязательна. С ней распознавание речи идёт примерно в 10 раз быстрее, результат тот же.

## Важно

Команда `/plugin` работает только в терминале (в программе `claude`), а не в приложении Claude для компьютера. Поэтому плагин ставится из терминала. Пользоваться им потом можно и в приложении.

## Шаг 1. Подготовка

**Windows.** Откройте PowerShell и выполните:

```powershell
winget install --id Git.Git -e
```

Потом закройте и снова откройте терминал.

**Linux (Ubuntu, Zorin OS, Mint).** Откройте терминал и выполните:

```bash
sudo apt install -y git curl tar
```

**Mac.** Откройте Терминал и выполните:

```bash
xcode-select --install
```

Если появится окно, нажмите «Установить». Если пишет, что всё уже установлено, переходите дальше.

## Шаг 2. Установка плагина

В терминале по очереди:

```bash
claude plugin marketplace add SirOxygenFish/reel-studio
```

```bash
claude plugin install reel-studio@siroxygenfish
```

## Шаг 3. Установка инструментов

Запустите Claude Code (в терминале или в приложении) и напишите:

```
/reel-setup
```

Первый раз это занимает от 10 до 30 минут. Всё ставится в отдельную папку плагина, система не меняется, пароль администратора не нужен. Когда Claude спросит разрешение на `reel-tool`, выберите «разрешать всегда».

## Шаг 4. Проверка

```
/reel-doctor
```

Если чего-то не хватает, doctor покажет готовую строку, которую нужно скопировать в терминал. На Linux это обычно одна команда `sudo apt install -y ...` для библиотек браузера.

## Как пользоваться

1. Положите видео в папку проекта.
2. Напишите Claude: «монтируй» или `/reel`.
3. Готовый Reel появится в папке `reels-done`.

Можно уточнить: «только лицо, без анимаций», «без лица, только анимация», «заголовок: ...». Если досняли исправление к уже готовому ролику, напишите «это исправление к последнему»: готовый монтаж сохранится, заменятся только переговорённые фразы.
